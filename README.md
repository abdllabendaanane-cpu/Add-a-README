## الفكرة / Concept

- **الشعار:**
  - كرة أرضية منقّطة بقاراتها الحقيقية ترمز إلى أخبار العالم.
  - مدار فيه إلكترون يرمز إلى العلوم.
  - كتاب مفتوح يرمز إلى التاريخ والثقافة، وهو مأخوذ من الشعار القديم.
- **الاسم:** `Al_3asr` بالكريمي، و`TV` على شارة ذهبية بأسلوب القنوات الإخبارية.
- **الأقسام:** أخبار • تاريخ • علوم • ثقافة، ولكل قسم أيقونة.
- **الأغلفة:** خريطة عالم منقّطة تضيء فيها مدن صنعت التاريخ والعلم، تربطها خطوط تشبه طرق المعرفة. المدن: فاس، قرطبة، تمبكتو، روما، أثينا، إسطنبول، القاهرة، دمشق، بغداد، سمرقند.
- **الألوان:** الكحلي والذهبي والكريمي من الهوية القديمة، مع لمسة فيروزية للعلوم.

## التعديل وإعادة التصدير / Editing and re-rendering

```bash
npm install
npm run studio   # معاينة وتعديل مباشر في المتصفح
npm run render   # تصدير الصور الثلاث إلى designs/
```

| الملف | المحتوى |
|---|---|
| `src/theme.ts` | الألوان والخطوط |
| `src/Brand.tsx` | كتابة الاسم `Al_3asr\|TV` وسطر الأقسام وأيقوناته |
| `src/GlobeEmblem.tsx` | الشعار (الكرة الأرضية والمدار والكتاب) |
| `src/WorldMap.tsx` | خريطة العالم والمدن والخطوط بينها |
| `src/Profile.tsx` و `src/Covers.tsx` | التصاميم الثلاثة |
| `src/v1/` | النسخة الأولى |

- لعرض حدود القص لكل منصة أضف `--props='{"guides":true}'` إلى أمر `remotion still`.
- نقاط الخريطة مولّدة من بيانات [world-atlas](https://github.com/topojson/world-atlas) بالأمر `node scripts/make-land-dots.mjs`.

**الخطوط:** Montserrat و Cairo و Reem Kufi، وكلها برخصة SIL Open Font License، وموجودة في `public/fonts/`.
